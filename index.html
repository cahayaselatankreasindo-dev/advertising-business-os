Pedoman Strategis Bisnis CSK
  • Paket UMKM: Mulai Rp 1.500.000 (Desain Logo Saja) untuk perputaran cash cepat.
  • Paket Menengah ke Atas: Mulai Rp 8.000.000 (Logo + Brand Guidelines + Stationery + Vector Editable) untuk margin tinggi.
  • Siklus Kas: Selalu terapkan sistem DP minimal 50% sebelum proyek produksi dimulai.
  • Product-Market Fit: Gunakan rating bintang di tab Klien untuk melacak kepuasan dan repeat order potential.
  • Marketing ROI: Catat setiap iklan di tab Marketing. Bandingkan CPL vs nilai deal ratarata untuk evaluasi efisiensi.

Pengaturan & Integrasi Cloud

Hubungkan aplikasi ke Google Sheets agar bisa dibuka dari HP mana saja secara real-time.

Koneksi Database Google Sheets (Gratis)

Masukkan URL Web App dari Google Apps Script Anda. Setelah terisi, data akan otomatis tersinkronisasi antara HP dan Komputer Anda.
Penting: Setelah deploy baru di Apps Script, jalankan fungsi setupSheet sekali untuk membuat tab baru.

Jalankan setupApiTokens() di Apps Script setelah backend baru di-deploy. Salin token sesuai peran. Token Tim hanya mengakses Leads, Klien, dan Proyek; token Owner memiliki akses penuh. Jangan bagikan token Owner.

Auto-Trigger Otomatisasi

Untuk mengaktifkan otomatisasi "Deal Menang → Pendapatan + Antrean Proyek", buka Apps Script editor, pilih fungsi installAutoTrigger, lalu klik Run. Ini akan memasang trigger onEdit & time-driven (per jam).
