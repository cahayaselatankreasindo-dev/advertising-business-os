Pedoman Strategis Bisnis CSK
  • Penjualan B2B: Catat kebutuhan, lokasi pemasangan, estimasi nilai, dan tanggal follow-up untuk setiap prospek.
  • Produksi: Pastikan gambar kerja, ukuran, material, revisi, dan tenggat sudah disepakati sebelum pengerjaan.
  • Keuangan: Pisahkan nilai deal, invoice, dan uang yang benar-benar diterima; jangan anggap deal sebagai DP.
  • Pengadaan: Susun HPP dan biaya pemasangan sebelum menentukan harga penawaran produk custom.
  • Pemasaran: Ukur CPL dari biaya dan lead aktual. ROAS baru valid bila penjualan ditautkan ke iklan yang menghasilkan transaksi.

Pengaturan & Integrasi Cloud

Simpan lokal lebih dulu. Data lintas perangkat hanya konsisten setelah penyimpanan cloud terverifikasi.

Koneksi Database Google Sheets (Gratis)

Masukkan URL Apps Script milik CSK dan token akses. Perubahan tetap tersimpan di perangkat sampai cloud mengonfirmasi melalui pembacaan ulang.
Penting: Jangan menjalankan setupSheet pada database produksi tanpa backup dan pemeriksaan migrasi. Endpoint yang belum aman jangan dipakai untuk data klien.

Gunakan token unik dari Script Properties Apps Script. Token di browser bukan login pengguna dan tidak menggantikan autentikasi server. Jangan bagikan screenshot pengaturan berisi token.

Pengakuan pembayaran dan otomatisasi

Mengubah lead menjadi Deal Menang tidak berarti DP sudah diterima. Catat pemasukan hanya setelah pembayaran benar-benar masuk. Jangan aktifkan trigger backend lama yang membuat jurnal DP otomatis dari nilai penawaran.

Cadangan Data Lokal (JSON)

Unduh backup data lokal untuk pemulihan. Token dan URL API tidak disertakan; simpan file secara privat. Perubahan yang masih mengantre perlu rekonsiliasi sebelum menghubungkan cloud lagi.
